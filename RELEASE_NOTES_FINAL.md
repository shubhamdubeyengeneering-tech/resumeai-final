# ResumeAI Final Release Notes

This package includes the latest stability fixes for ResumeAI.

## Included
- Resume upload and analysis workflow
- Resume validation and evidence-based scoring
- Dashboard, profile, settings and applications
- AI Career Chat with current-message language guidance
- Mock interview with English/Hindi selection and voice support
- Resume enhancement templates
- Job search and filters present in the source package
- Security PIN create/change/enable/disable/remove flows
- Light-only appearance UI and English-only website language selector

## Run locally
```powershell
npm install
npm run build
npm run dev
```

Keep your `.env` file and API keys outside the ZIP.
